# MEP-0001 Openshift-SCN profiles

Data 08/21/2025
Author: Adrian Riobo <ariobolo@rednat.com>

## Proposal

The idea for Openshift-SNC profiles is to allow a new flag as a comma separated list of values to install official operators on top of SNC to allow automatically deploy an Opensihft functionality.

Although from a point of view of isolation of concerns this could be done right after provision SNC with Mapt...it is a very common case for different teams to direcly have access to some of the operators already installed on the cluster..so instead of translating to them
or to have an orchestrator system in order to do so it should be a plus for us offers this.

The idea would be someting like....

mapt aws openshift-snc create ... --profiles rhoai

I would suggest to start a PoC for this using rhoai and see if the same strategy can be reused by other profiles...maybe virtualization? as then we can use that when running snc and setting mapt with nested-virtualization (so the cluster should be able to run virtualization 
profile)
